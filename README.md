# NGO Website — Micro Project

My first web development project, created as part of the diploma syllabus as a micro-project. Developed during the initial stages of learning HTML and CSS, this website helped me understand the fundamentals of web development, including webpage structure, styling, layouts, and content organization.

Later, during my internship, I revisited and updated the website while learning Bootstrap. I incorporated Bootstrap components and responsive layouts to improve the overall presentation and adaptability across different screen sizes, while preserving the original structure and content of the project.

This project represents one of my earliest steps into web development and reflects my learning progression from basic HTML and CSS to building more structured and responsive frontend interfaces.

## 🛠️ Technologies Used

HTML5 · CSS3 · Bootstrap
